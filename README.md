# Trekking Management Application

## Requirements

- Python 3.x
- Flask
- Flask-SQLAlchemy

## Installation

Install the required packages:-

pip install Flask Flask-SQLAlchemy

## Running the Application

Run the following command:

python app.py

The SQLite database and the default Admin account will be created automatically on the first run.

Open your browser and visit:

http://127.0.0.1:5000
